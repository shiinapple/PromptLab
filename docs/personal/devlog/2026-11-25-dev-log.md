## 今天确认的项目和协作要求

- **产品边界。** 做中英文 Prompt 练习站。首版纯 BYOK，浏览器直连和 D0 手动导出导入都保留，Java 负责按题目规则做严格 JSON 判题。目标是低配服务器可部署、可维护的练习闭环。
- **推进方式。** 先确认方案，再按小任务执行，先用 PoC 验证会影响设计的假设。优先使用成熟开源组件，实际版本以验证结果为准。方案、原理和报告分析可交给 Chat，仓库改动、构建与实测由 Codex 执行。早期讨论与学习线索可以回看本机的开发与学习笔记。
- **证据口径。** 本机 Mock、真实 HTTPS 网关和正式产品进度各有验收范围。PoC 暂按 `stop` 后收到 `[DONE]` 判断 SSE 正常结束，真实网关是否符合该约定仍待验证。客户端连接断开也无法据此确认真实上游停止生成或计费。
- **文档用途。** 每次任务报告留在 `docs/personal/reports/`，便于查改动和测试结果。个人日志留在 `docs/personal/`，便于回顾当天工作和接续计划。以权威设计文档和执行记录核对当前状态。
