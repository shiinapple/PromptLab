## 待验证依赖

- POC-04 已验证一套 Java 21、Boot MVC、SQLite JDBC、Spring JDBC、HikariCP、Flyway 与 Jackson 工作组合。M0 将该组合用作可复现基线，核对正式工程的依赖支持、锁定版本、许可及干净构建。调整核心组合时只复验受影响路径。[版本与 PoC 证据](validation/POC-04.md#poc-04-执行记录)
- M1 采用本地 2020-12 封闭子集（见 [POC-05](validation/POC-05.md)），未引入通用 Schema 库。networknt 等候选库与 Jackson、本地引用和资源上限的兼容验证后置，仅在需要扩展词汇范围时再评估。SSE 解析已通过 POC-01 和 M2 打包前端的本机 Mock 验证。真实网关兼容性、部署资源和目标环境在 M6/M7 验收。

## 后置触发条件

- P1：公网 CORS 成为主要阻塞且 D0 成本不可接受，经安全与资源验证后另行确认。
- P2：主要阻塞是本机网关且用户确有自动化需求。
- 视觉题：真实模型、受信题图、图片大小、导入导出均通过后发布。
- 平台免费额度、Agent 工具调用、任意用户图片自动判题、重型编辑器：独立需求评审。
