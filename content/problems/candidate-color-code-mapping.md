# 候选教学题：颜色编号映射

状态为候选。依据 [POC-03 T2](../../docs/validation/POC-03.md)。

## 练习目标

使用多条验收用例同时检查输出形式和输入到输出的映射。解释为什么只检查「是一个小写颜色词」会放过常量答案。

## 学生任务

只编辑 System Prompt。每次用户提供一个颜色编号。让模型只返回对应的小写英文颜色名，不带空格、换行、标点或解释。输入范围为 R、G、B。

| 用例 | User Prompt | 完整期望原文 |
|---|---|---|
| M01 | `Color code: R` | `red` |
| M02 | `Color code: G` | `green` |
| M03 | `Color code: B` | `blue` |

## 验收

将完整原文与当前用例的期望字符串精确比较，区分大小写，不做 trim。M01 的 `Red` 和 `red ` 均失败，M02 的 `red` 格式正确但映射错误。整题需覆盖三个输入。判断超时、缺失正文或截断时沿用实验的错误分类。

先预测固定输出小写 `red` 会通过哪些用例，再写出包含完整映射和输出格式的提示。学生应能说明由哪条规则拒绝哪种答案。

## 实验观察

现场 FIXED 组六次输出 `Red`，通过 0/6。MAPPING 组通过 6/6。理论上的小写常量解只能通过 M01，是验收规则的推导。两种结果都可在[实验记录](../../docs/validation/POC-03.md#poc-03-单次-smoke-与主实验复测)核对。
