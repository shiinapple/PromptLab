# 012 切换语言后直连错误提示残留旧语言

**状态** `FIXED`

## 现象

在中文界面触发模型 HTTP 401，再切换到英文。题面、运行状态和排查要点切到英文，页面级错误提示仍是中文。

## 原因与修复

直连逻辑在请求失败时把按当时语言生成的字符串写入页面状态。现在反馈状态保留生成文案的函数，渲染时根据当前语言生成错误提示。D0 和草稿操作的状态提示也走同一条渲染路径。

## 验证

`npm run test:m5` 的 A6 在中文界面触发本机 mock 的 HTTP 401，保留该运行并切到英文。断言页面文案和可访问标签不含中文残留或裸露的 `errors.*` key，再执行英文 D0 和直连成功、失败流程。
