# 007 读题接口只返回当前版本

读代码所得。判题已经按运行记录的版本加载题包（`PracticeRuns.submit` 调用 `loadVersion`），但 `GET /api/problems/{id}` 只返回当前发布版本。页面用 `?run=` 恢复旧运行时，左侧题面和用例来自新版本。

现在每题只发布过 v1，所以还看不到。**给 002 增加用例就会发布 v2**（见 [008](008-single-case.md)），本问题要先解决。

**期望**：接口支持读取已发布过的旧版本，页面按运行的版本显示题面。见 [API 契约](../design/API.md#m3-接口变更待实现)。
