## 建议状态机（待确认 Q04/Q09）

- 创建：PENDING。DIRECT 客户端显示连接/流式阶段；D0 客户端显示等待导入。无需服务端实时流式状态。
- 合法完整正文：原子进入 JUDGED，verdict 为 PASSED / FORMAT_ERROR / WRONG_ANSWER。格式错误是判题结果，不是传输失败。
- 故障或取消：原子进入 FAILED / CANCELLED，仅保存脱敏故障码，不判题。
- 过期：PENDING → EXPIRED；拒绝之后提交正文。没有自动重试模型调用。
- 同用户、同幂等键的创建请求若内容一致返回原 run；冲突内容返回 409。结果重试按服务端规范化结果比较；不一致拒绝。授权检查先于状态泄露。
- 归档仅针对已判题运行，重复归档不新建、不重新推理；失败判题允许归档，传输故障不归档。

以上为新增设计建议，确认后同步进 ARCHITECTURE/UI；未确认前不实施状态契约。

## 暂不需要的设计

不必提前细化微服务、代理部署、用户上传任意规则、完整插件系统、独立配置中心、视觉 Agent 工具或原生多协议 SDK。它们不是文本 MVP 的前置条件。
