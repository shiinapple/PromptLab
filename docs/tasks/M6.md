  - 申请、查询、撤回三个接口，均需会话与 CSRF（见 API.md 的“账号删除”）。

  - 到期删除由服务端定时任务执行，执行时复查记录仍有效且未撤回；删除依赖外键级联。

- 验收：
  - 申请后 3 天内可撤回，撤回后不会被删除；重复申请幂等。
  - 到期后账户无法登录，业务接口返回 401 或 404，关联数据被删除。
  - 跨账号访问保持 404；删除不影响其他账户。
  - 定时任务在服务重启后仍能正确执行，且只删除到期记录。
  - 测试覆盖：反悔期边界（2 天 23 小时与 3 天整）、并发申请与撤回、删除中途失败后重试。
- 依赖：M4 账户与会话（已完成）；Q04 文案定稿。
